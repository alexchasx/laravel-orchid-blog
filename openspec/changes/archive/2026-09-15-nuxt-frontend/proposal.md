## Why

Публичный фронтенд блога — Blade + кастомный SCSS образца 2022 года: устаревший дизайн, слабая адаптивность на мобильных, нет тёмной темы, ограниченные SEO-возможности. Блогу нужен современный «воздушный» дизайн на Nuxt 4 + Vue 3 + Vuetify 3 с SSR для SEO, который легко поддерживать и расширять.

## What Changes

- Создаётся новый Nuxt 4 SSR-фронтенд в монорепозитории (папка `frontend/`) на стеке Vue 3 (`<script setup>`) + Vuetify 3.
- Создаётся новый Laravel JSON API для публичной части: список статей (пагинация, поиск, фильтры по рубрике/тегу), страница статьи, рубрики, теги.
- Реализуются страницы: главная (список с превью), статья, рубрика, тег, поиск, «О блоге», контакт.
- Добавляется переключатель тёмной/светлой темы Vuetify с сохранением выбора.
- SEO: корректные заголовки, мета-описания, Open Graph на странице статьи, семантика HTML, серверный рендеринг.
- Производительность: ленивая загрузка изображений, tree-shaking Vuetify, минимум сторонних зависимостей (без дополнительных UI-библиотек и `@nuxt/content` — контент отдаётся готовым HTML).
- **BREAKING**: публичный фронтенд переходит с Blade/SCSS на Nuxt; новые изменения в Blade-вьюхи публичной части не вносятся.

Non-goals этого этапа: аутентификация (Breeze) и комментарии остаются на Blade; старые Blade-вьюхи публичной части не удаляются (остаются рабочими до полного переключения и служат fallback); админка Orchid не меняется.

## Capabilities

### New Capabilities

- `blog-api`: Laravel JSON API публичного блога — статьи (пагинация, поиск, фильтры по рубрике/тегу), отдельная статья, список рубрик и тегов, CORS для фронтенда.
- `nuxt-public-site`: публичный сайт блога на Nuxt 4 SSR — страницы (главная, статья, рубрики, теги, поиск, «О блоге», контакт), компоненты Vuetify 3, тёмная/светлая тема, SEO-мета, адаптивная вёрстка.

### Modified Capabilities

- `frontend-build`: публичный фронтенд больше не собирается через Vite/Blade — сборка и запуск переходят на Nuxt 4 (`frontend/`); Vite остаётся только для Breeze-шаблонов аутентификации.
- `frontend-design`: дизайн-система публичного фронтенда переходит с SCSS-токенов на темы Vuetify 3 (light/dark, типографика); требования про `resources/sass/style.scss` и CSS custom properties перестают действовать для публичной части.

## Impact

- Laravel: `routes/api.php`, `app/Http/Resources/*` (ArticleResource, RubricResource, TagResource), `config/cors.php`, обновление `frontend-build`/`frontend-design` spec.
- Nuxt: новый проект `frontend/` — `nuxt.config.ts`, `app/` (pages, components, layouts, composables, plugins), зависимости `nuxt`, `vuetify`.
- Blade: публичные вьюхи (`index`, `article`, `contact`, `layouts/base`, `includes/sidebar`) без изменений в этом этапе; auth-вьюхи без изменений.
- Конфигурация: CORS-разрешения для origin Nuxt в dev/prod.
