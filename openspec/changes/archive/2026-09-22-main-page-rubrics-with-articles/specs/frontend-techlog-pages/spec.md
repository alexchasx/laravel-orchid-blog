## Purpose

Контентные страницы публичного блога: главная (hero, masonry-сетка статей, topics, about, newsletter), статья (hero-image, TOC, prose, tags, комментарии), контакты (имя, email, сообщение).

## MODIFIED Requirements

### Requirement: Главная страница

Раздел **Topics** переведён с фиксированного списка из 4 тем на динамический список рубрик из БД: выводятся только рубрики с хотя бы одной опубликованной статьёй (`is_published = true` и `published_at <= now()`). Секция полностью скрывается, если таких рубрик нет. Ссылки строятся через маршрут `showByRubric` с объектом рубрики.

#### ADDED Scenarios:

##### Scenario: Рубрика с опубликованной статьёй отображается

- **WHEN** в базе есть рубрика с хотя бы одной опубликованной статьёй
- **THEN** в секции Topics выводится ссылка на эту рубрику с её названием

##### Scenario: Рубрика без опубликованных статей скрыта

- **WHEN** у рубрики нет опубликованных статей (включая рубрики только с черновиками или запланированными статьями)
- **THEN** ссылка на рубрику не выводится

##### Scenario: Нет рубрик с опубликованными статьями

- **WHEN** ни одна рубрика не имеет опубликованных статей
- **THEN** секция Topics не отображается на главной странице
