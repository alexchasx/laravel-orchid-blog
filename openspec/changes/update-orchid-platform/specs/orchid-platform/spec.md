## Purpose

Определяет требования к объявлению зависимости `orchid/platform` в проекте: проект использует последнюю стабильную версию 14.x (не ниже 14.53), а установка допускается только после обновления окружения до совместимого с Orchid 14.

## ADDED Requirements

### Requirement: Объявление версии orchid/platform
Проект MUST объявлять зависимость `orchid/platform` в `composer.json` с ограничением версии `^14.53`.

#### Scenario: Версия объявлена корректно
- **WHEN** проверяется секция `require` в `composer.json`
- **THEN** присутствует запись `"orchid/platform": "^14.53"`

#### Scenario: Проверка соответствия окружения
- **WHEN** выполняется `composer update` или `composer install` для установки Orchid 14
- **THEN** установка MUST завершиться успешно только при наличии Laravel `^10.0 || ^11.0 || ^12.0 || ^13.0` и совместимого PHP, иначе Composer MUST сообщить о несовместимости без внесения изменений в lock-файл

### Requirement: Порядок обновления окружения
Установка Orchid 14 на проект с текущим Laravel 9 невозможна; перед фактической установкой версии `^14.53` окружение MUST быть обновлено (Laravel и PHP).

#### Scenario: Установка при устаревшем окружении
- **WHEN** строка версии изменена на `^14.53`, а Laravel всё ещё `^9.2`
- **THEN** изменение строки версии в `composer.json` разрешено, но `composer install`/`composer update` MUST оставаться невыполненным до тех пор, пока пользователь не обновит Laravel/PHP

### Requirement: Миграция кода приложения под Orchid 14
Код, использующий API Orchid (провайдеры, экраны, layout, конфигурация `config/platform.php`), после фактического перехода на Orchid 14 MUST быть приведён в соответствие с новым API.

#### Scenario: Адаптация кода
- **WHEN** Orchid 14 фактически установлен
- **THEN** все используемые API Orchid в `app/Orchid/` и `config/platform.php` MUST работать без ошибок совместимости
