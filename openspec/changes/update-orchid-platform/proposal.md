## Why

Проект использует устаревшую версию `orchid/platform` (`^12.4`), которая не получает актуальных исправлений и функций. Требуется перейти на последнюю стабильную версию **14.53.0**, чтобы использовать современное API и исправления Orchid.

При этом по решению пользователя в рамках этого изменения обновляется **только строка версии** в `composer.json`. Само обновление Laravel/PHP, необходимое для установки Orchid 14, выполняется пользователем отдельно и позже.

## What Changes

- Обновить объявление зависимости `orchid/platform` в [`composer.json`](../../composer.json:18) с `^12.4` на `^14.53`.
- Зафиксировать в задачах обязательное последующее обновление окружения (Laravel >= 10/11 и совместимый PHP), без которого `composer install`/`composer update` не разрешится.
- **BREAKING**: Orchid 14 — новый мажор. Требует Laravel `^10.0 || ^11.0 || ^12.0 || ^13.0` (актуальные ветки 10/11+), более новый PHP и обновлённые сопутствующие пакеты (`orchid/blade-icons`, `tabuna/breadcrumbs`, `laravel/scout` и др.). Сам запуск Composer-установки Orchid 14 с текущим Laravel 9 невозможен.

## Impact

- [`composer.json`](../../composer.json:18) — изменение строки версии `orchid/platform`.
- [`composer.lock`](../../composer.lock) — будет пересобран при установке.
- Окружение: Laravel `^9.2` и PHP `^8.0.2` несовместимы с Orchid 14; потребуется последующее обновление зависимостей пользователем.
- Конфигурация/провайдеры Orchid в `config/platform.php`, `app/Orchid/` могут требовать адаптации под новое API (выполняется позже, вне рамок данного изменения).
