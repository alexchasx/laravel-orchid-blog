# frontend-techlog-search

## Purpose

Поиск по статьям блога: по заголовку и по content_html через LIKE-запросы.

## Requirements

### Requirement: Поиск по заголовку и контенту

Метод `ArticleController@index` **SHALL** поддерживать поиск по параметру `?search=`:

- Поиск по `$article->title` (LIKE)
- Поиск по `$article->content_html` (LIKE, с HTML-тегами)
- Результат — отсортированный по `published_at DESC`, пагинированный (6 на страницу)

#### Scenario: Поиск по заголовку

- **WHEN** пользователь вводит «архитектура» в поисковую строку
- **THEN** возвращаются статьи, где `$title LIKE '%архитектура%'`

#### Scenario: Поиск по контенту

- **WHEN** пользователь вводит «Kubernetes» в поисковую строку
- **THEN** возвращаются статьи, где `$content_html LIKE '%Kubernetes%'`

#### Scenario: Поиск не найден

- **WHEN** по запросу не найдено ни одной статьи
- **THEN** отображается «Ничего не нашлось»

#### Scenario: Пустой поиск

- **WHEN** параметр `?search` отсутствует или пустой
- **THEN** отображаются все опубликованные статьи без фильтрации
