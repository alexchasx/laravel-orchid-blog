# TECH//LOG — многостраничный ИТ-блог

Готовая статическая вёрстка на чистом HTML, CSS и vanilla JavaScript.

## Файлы
- `index.html` — главная страница
- `article.html` — шаблон полноценной статьи
- `contact.html` — страница обратной связи
- `styles.css` — дизайн, адаптивность, неоморфизм, light/dark
- `script.js` — меню, тема, scroll reveal, кнопка «Наверх», клиентская валидация

## Запуск
Откройте `index.html` напрямую или отдайте папку через любой статический сервер.

## Что заменить перед production
1. Заменить демонстрационные ссылки GitHub/Telegram/LinkedIn и `hello@example.com`.
2. Подключить реальный backend/API для форм.
3. Добавить реальные изображения, favicon, Open Graph image и canonical URL.
4. Для production желательно self-host шрифтов или настроить CSP/политику внешних ресурсов.
